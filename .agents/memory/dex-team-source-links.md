---
name: DEX team source-link policy
description: Why some CryptoKiller team records link to the DEX team directory instead of guessed individual profile routes.
---

Only use DEX individual profile URLs that return a live page. Do not derive a profile URL from a person's slug; use the DEX team directory as the source link when no live individual page is available.

**Why:** Most plausible slug-shaped DEX team URLs returned 404 during the team-credibility work. Linking those routes would weaken the source attribution the feature is meant to provide.

**How to apply:** When adding or refreshing a team member, verify the source URL. Preserve a working individual profile when one exists; otherwise link the live team directory and never fabricate a more specific route.
